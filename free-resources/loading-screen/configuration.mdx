All runtime options live in **`config.js`** at the root of `bundly-loadingscreen`. There is no build step. Edit the file, restart the resource, and reconnect to see changes.

```js
const Config = {
    server: { /* ... */ },
    socials: [ /* ... */ ],
    discord: { /* ... */ },
    music: { /* ... */ },
    background: { /* ... */ },
};
```

<Warning>
  Logo, background, and music must be files inside this resource. Remote URLs and streams are ignored. Paths are relative to `web/index.html`, so `assets/logo.png` is `web/assets/logo.png`.
</Warning>

## Server name and logo

```js
server: {
    logo: 'assets/logo.png',
    name: {
        first: 'Bundly',
        second: 'Roleplay',
    },
    slogan: 'Bundle What Belongs Together.',
},
```

| Option | What it does |
| --- | --- |
| `logo` | Local image path. Shown at the top of the screen. Leave invalid paths out and the default `web/assets/logo.png` in the HTML still loads. |
| `name.first` | First line of the server name. Large type. |
| `name.second` | Second line. Hidden if you leave it empty. |
| `slogan` | Line under the name. |

Put your logo in `web/assets/` and point `logo` at it. PNG with a transparent background works best.

## Social buttons

Square icon buttons. Each one opens in the player's browser.

```js
socials: [
    { icon: 'fa-solid fa-globe', url: 'https://bundlyscripts.com' },
    { icon: 'fa-brands fa-x-twitter', url: 'https://x.com/bundlyscripts' },
    { icon: 'fa-brands fa-youtube', url: 'https://youtube.com/@bundlyscripts' },
],
```

| Option | What it does |
| --- | --- |
| `icon` | Font Awesome class list, for example `fa-brands fa-youtube`. |
| `url` | `http` or `https` link. Anything else is skipped. |

Add or remove entries in the array. A button is only created when both `icon` and `url` are valid.

## Discord button

```js
discord: {
    label: 'join discord',
    icon: 'fa-brands fa-discord',
    url: 'https://discord.gg/CnQcfsw9G',
},
```

| Option | What it does |
| --- | --- |
| `label` | Button text. Defaults to `join discord` if you leave it empty. |
| `icon` | Font Awesome class list. Defaults to `fa-brands fa-discord`. |
| `url` | Invite or Discord URL. Set `url` to `''` to hide the button. |

## Music

Audio files go in `web/assets/`. Remote and streaming links are not supported.

```js
music: {
    enabled: true,
    volume: 40,
    tracks: [
        'assets/music.mp3',
    ],
},
```

| Option | What it does |
| --- | --- |
| `enabled` | `false` hides the player and plays nothing. |
| `volume` | Default volume from `0` to `100`. Players can still change it on the screen. |
| `tracks` | Local paths. One track loops. Several tracks play in order, then repeat. |

The play/pause control and volume slider appear when music is enabled and at least one valid track is listed.

<Note>
  When `background.video_music` is `true`, these tracks are ignored. The same controls drive the video's own audio instead.
</Note>

## Background

```js
background: {
    type: 'image',
    image: 'assets/background.jpg',
    video: '',
    video_music: false,
},
```

| Option | What it does |
| --- | --- |
| `type` | `'image'` or `'video'`. |
| `image` | Local image path used when `type` is `'image'`. |
| `video` | Local video path used when `type` is `'video'`. |
| `video_music` | `true` plays the video audio through the music controls and ignores `music.tracks`. `false` keeps the video muted and uses the music playlist. |

Example with a looping video and its own audio:

```js
background: {
    type: 'video',
    image: 'assets/background.jpg',
    video: 'assets/background.webm',
    video_music: true,
},
```

Keep both `image` and `video` files in `web/assets/`. Only the one matching `type` is used.

<Tip>
  `webm` is a solid choice for FiveM loading screens. Keep the file size reasonable so players are not waiting on the video itself.
</Tip>

## Allowed local paths

Media paths are checked before they play. A path is accepted only if it is:

- Relative to `web/index.html`
- Without `..`, `:` , `//`, or a leading `/`
- Made of letters, numbers, `_`, `.`, `/`, spaces, and `-`

Valid: `assets/logo.png`, `assets/music/theme.mp3`

Rejected: `https://example.com/logo.png`, `../other-resource/file.png`, `C:/videos/bg.webm`

## Brand colors

Colors are CSS variables in `web/css/main.css`. Values are **RGB triplets** without `rgb()`.

```css
:root {
    --color-background: 0, 0, 0;
    --color-primary: 128, 228, 79;
    --color-accent: 23, 39, 15;
    --color-text-primary: 255, 255, 255;
    --color-text-accent: 158, 158, 158;
}
```

| Variable | Where it shows |
| --- | --- |
| `--color-background` | Fallback behind the image/video, button fills |
| `--color-primary` | Progress bar, Discord button, hover states |
| `--color-accent` | Dark overlay on top of the background |
| `--color-text-primary` | Server name and main text |
| `--color-text-accent` | Slogan |

The default primary `#80E44F` matches the Bundly brand. Change it to your server color.

## Full example

```js
const Config = {
    server: {
        logo: 'assets/logo.png',
        name: {
            first: 'Bundly',
            second: 'Roleplay',
        },
        slogan: 'Bundle What Belongs Together.',
    },

    socials: [
        { icon: 'fa-solid fa-globe', url: 'https://bundlyscripts.com' },
        { icon: 'fa-brands fa-youtube', url: 'https://youtube.com/@bundlyscripts' },
    ],

    discord: {
        label: 'join discord',
        icon: 'fa-brands fa-discord',
        url: 'https://discord.gg/CnQcfsw9G',
    },

    music: {
        enabled: true,
        volume: 40,
        tracks: [
            'assets/music.mp3',
        ],
    },

    background: {
        type: 'image',
        image: 'assets/background.jpg',
        video: '',
        video_music: false,
    },
};
```

## After you edit

Restart the resource and reconnect. If you only changed `config.js` or files in `web/assets/`, `ensure bundly-loadingscreen` is enough.

```cfg
ensure bundly-loadingscreen
```

If branding does not update, hard-reconnect rather than using `reconnect` from an already-loaded session. The loading screen only runs while the client is loading.
